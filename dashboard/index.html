MEASURED, NOT MADE UP

Inside the intelligence.

Models learn from actual SUMO journeys. Signal safety remains deterministic.

01 · PREDICTION

Linear Regression

Predicts conventional remaining travel time using distance, vehicle count, speed, queue length, edge count and traffic demand.

Training status loading…
02 · PRIORITY ADMISSION

Logistic Regression

Estimates whether granting trip-level priority is beneficial. A separate controller manages yellow, all-red and protected movement phases.

03 · CONGESTION

K-Means clustering

Groups measured traffic states into low, medium and high congestion. Clusters are ordered by queue, vehicle count and speed.

Standardized features · 3 clusters
04 · BENCHMARK

Random Forest

Alternative travel-time predictor, evaluated against Linear Regression on held-out seeds.

Virtual sensing, real simulation data.

GPS comes from SUMO vehicle coordinates. E2 lane-area detectors measure queues, count, speed and occupancy. E1 induction loops measure point crossings. Emergency status comes from dispatch, not a sensor.

Prototype models are trained on this synthetic city only. No real-road deployment or field accuracy is claimed. Counterfactual training uses a documented cost tradeoff; it is not an optimized municipal traffic policy.
