# 2. CORE OBJECTIVE

Develop an intelligent traffic management simulation capable of detecting emergency vehicles, analysing real-time traffic conditions, predicting congestion, selecting efficient ambulance routes, and dynamically coordinating traffic signals to establish a green corridor.

The system must demonstrate measurable improvements over conventional traffic signal operation.

This is a software-based simulation. No physical sensors, cameras, GPS devices, or hardware are required.

# 3. REQUIRED ARCHITECTURE

Implement a modular architecture consisting of:

A. SUMO TRAFFIC SIMULATION
- Load existing SUMO road networks.
- Support custom network configurations.
- Simulate vehicles, traffic density, intersections, and traffic lights.
- Generate configurable traffic scenarios.
- Support normal and emergency traffic conditions.
- Allow ambulance insertion at configurable locations.

B. PYTHON INTELLIGENCE ENGINE
Use Python as the central control system.

Responsibilities:
- Start, stop and control SUMO through TraCI.
- Identify emergency vehicles.
- Extract vehicle positions, speeds, routes and directions.
- Monitor traffic density and queue lengths.
- Identify congested intersections.
- Calculate ambulance travel-time estimates.
- Coordinate signal priority.
- Maintain simulation logs.

C. AI AND MACHINE LEARNING ENGINE

Implement actual working machine learning modules:

1. Traffic State Classification
- Use K-Means clustering or another justified clustering algorithm.
- Identify low, medium and high congestion states.
- Extract relevant traffic features.

2. Travel Time Prediction
- Implement a regression-based prediction model.
- Use traffic density, vehicle count, average speed, queue length and route distance.
- Compare predicted travel time against actual travel time.

3. Dynamic Route Selection
- Evaluate alternative ambulance routes.
- Include congestion and expected signal delays.
- Select the route with the lowest estimated travel cost.

4. Adaptive Signal Coordination
- Detect approaching emergency vehicles.
- Estimate arrival time at upcoming intersections.
- Prioritize the ambulance route.
- Create and maintain a green corridor.
- Restore normal traffic signal operation after passage.
- Prevent conflicting or unsafe signal phases.

Do not falsely label simple conditional rules as machine learning.
